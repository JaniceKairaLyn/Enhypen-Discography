# ENHYPEN Discography Explorer 💜

A custom, interactive web app built to explore the discography of K-pop group ENHYPEN.

This project is just for fun. I didn't include all the albums and songs they have released until November, 2026.

I am just an Engene and Ever who support Enhypen and Evan. And I am just a curious learner who is willing to learn something always. Thank you very much y'all.

## Features
*   **Album Grid:** View all ENHYPEN albums beautifully displayed.
*   **Tracklists:** Click any album to see its full tracklist in a modal.
*   **YouTube Search:** Click any song name to instantly search for it on YouTube.
*   **Filtering:** Filter albums by "Mini Album" or "Studio Album".
*   **Smart Search:** Search by album title OR by specific song names! The popup will even filter to show only the matching songs.

## Technologies Used
*   HTML5
*   CSS3 (Flexbox & Grid)
*   Vanilla JavaScript (DOM manipulation, Fetch API, Array filtering)
*   JSON for data storage

## How to Run Locally
1. Clone this repository.
2. Open the folder in VS Code.
3. Run a local server (e.g., using the Live Server extension or `python -m http.server`).
4. Open `http://127.0.0.1:8000` in your browser.
